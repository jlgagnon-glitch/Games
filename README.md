# Games

Browser games you can play on a computer, tablet or phone. There is nothing to install.

## ▶ Play: [jlgagnon-glitch.github.io/Games](https://jlgagnon-glitch.github.io/Games/)

That link opens the menu with every game. To play one directly:

| Game | What it is |
| --- | --- |
| [Rebound Robots 5](https://jlgagnon-glitch.github.io/Games/rebound-robots-5.html) | Robots slide until they hit something. Find the fewest moves to reach the target. Solo or party play. |
| [Pitch](https://jlgagnon-glitch.github.io/Games/pitch.html) | The card game Pitch, against three computer players. |
| [Turncoat](https://jlgagnon-glitch.github.io/Games/turncoat.html) | Five in a row on a six-sided board, where trapped pieces switch sides. Play the computer or a friend. |
| [Physics Proving Ground](https://jlgagnon-glitch.github.io/Games/physics-proving-ground.html) | Launch puzzles for intro mechanics: motion, forces, energy and rotation. |
| [Ohm Grid](https://jlgagnon-glitch.github.io/Games/ohm-grid.html) | A resistor tile game. Build circuits and chase secret goals. |
| [Vector Duel](https://jlgagnon-glitch.github.io/Games/vector-duel.html) | A space battle played with vector addition. |
| [Beamline](https://jlgagnon-glitch.github.io/Games/beamline.html) | A logic puzzle. Use mirrors, splitters and color filters to light every crystal and miss every bomb. |
| [Mirror Twins](https://jlgagnon-glitch.github.io/Games/mirror-twins.html) | A logic puzzle. One set of controls moves two twins in mirrored rooms. Get both onto their goals at once. |
| [Mandelbrot Explorer](https://jlgagnon-glitch.github.io/Games/mandelbrot.html) | Zoom into the Mandelbrot set as deep as you like, colored by how fast each point escapes. |

On an iPad, tap Share → Add to Home Screen to keep a game handy.
